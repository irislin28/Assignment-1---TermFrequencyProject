## How to Run the Program
Please open your terminal, **navigate into the `src` folder**, and execute the following exact commands:

```bash
# Step 1: Change directory to the 'src' folder
cd src

# Step 2: Compile the Java source code
javac TermFrequency.java

# Step 3: Run the program with the input text file argument
java TermFrequency pride-and-prejudice.txt
```
